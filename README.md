# wize.io

Francesco Bonomi’s portfolio, built with Next.js, React, TypeScript, and CSS Modules.

## Development

Use Node.js 24.19.0 and pnpm 10.34.5.

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project structure

`app/page.tsx` composes the portfolio page. Its interactive UI lives in
`app/_components/` with colocated CSS Modules, and the project and social links
live in `app/_data/links.ts`. Site-wide styles and metadata stay in the root
layout.

## Articles

Create a draft with `pnpm article:new "Your article title"`. The command generates
a five-character Nano ID once, creates
`content/articles/<initial-title-slug>/index.mdx` from
`scripts/templates/article.mdx`, registers it, and prints its local preview URL.
If that folder name exists, the command appends the ID. The folder can keep its
original name if you later edit the title.
Keep the ID in the MDX metadata; it is the article's permanent identity. The
readable part of `/articles/<id>-<title-slug>` is derived from the title with
`@sindresorhus/slugify`. Changing a title changes the canonical URL, while the
ID lets old title URLs redirect to it. Use `slugOverride` in the metadata only
when a title produces an awkward slug.

Write the article body in the MDX file and keep its images beside it. A new
article starts with `draft: true` and no `publishedAt`. Add its description,
tags, and `publishedAt: 'YYYY-MM-DD'`, then set `draft: false` to publish it.
`createdAt` and the ID stay unchanged. Drafts appear locally but are excluded
from production article routes, the RSS feed, and the sitemap.

The article registry in `content/articles/registry.generated.ts` is generated by
the creation command. If you add or move an MDX file by hand, run
`pnpm article:sync`; `pnpm article:check` checks that it is up to date.

The Mowji article is a draft based on the supplied page preview. Start the dev
server and open
`http://localhost:3000/articles/f66dn-the-glass-looked-broken-because-the-window-was-behaving-correctly`
to review it.

Use Markdown code fences with a language name for highlighted code blocks.
Import local images into the MDX file and render them with `ArticleImage`, which
accepts `alt`, optional `caption`, and optional `cropped` props. Keep local MP4
files beside the MDX file, import them, and render them with `ArticleVideo` using
the video's pixel `width` and `height`. Hosted video can use `VideoEmbed` with
`provider="youtube"` or `provider="vimeo"`, a `videoId`, and a descriptive
`title`. Headings at level two receive linkable IDs; for a
long article, add an optional `toc` array to the article metadata with entries
matching those IDs.

## Quality checks

```bash
pnpm article:check
pnpm format:check
pnpm lint
pnpm typecheck
pnpm build
```

## Releases

Run `pnpm release:dry` to preview the next version and changelog. Run `pnpm release` to update the version, changelog, commit, and tag using standard-version.
